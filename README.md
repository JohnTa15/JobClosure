# JobClosure

Εφαρμογή για βιντεολήπτες που καλύπτουν γάμους, βαφτίσεις, σχολικές εκδηλώσεις και παραστάσεις -
**Android** (κινητό) και **desktop** (Windows/macOS/Linux), με συγχρονισμό μεταξύ τους μέσω Google
Calendar. Κρατάει σε ένα σημείο ποιες δουλειές έχεις ήδη κλείσει ώστε να μην πέσεις σε διπλή
κράτηση, δείχνει αν χρειάζεται drone και αν υπάρχει δεξίωση μετά την εκκλησία, υπολογίζει τον χρόνο
διαδρομής από το σπίτι μέχρι την εκκλησία (και από την εκκλησία μέχρι το κέντρο δεξίωσης), και
προσθέτει αυτόματα το ραντεβού στο ημερολόγιο της συσκευής (Google Calendar ή Samsung Calendar -
ό,τι χρησιμοποιείς) με υπενθύμιση 2 ώρες πριν.

Το κινητό (Android) έχει όλες τις λειτουργίες παρακάτω. Ο desktop client καλύπτει το βασικό:
λίστα/προσθήκη/επεξεργασία κρατήσεων με έλεγχο σύγκρουσης, συγχρονισμένο με το κινητό μέσω Google
Calendar· ο καιρός/άνεμος/υψόμετρο, ο έλεγχος ζωνών drone και ο in-app updater είναι προς το παρόν
μόνο στο Android.

## Λειτουργίες

- **Λίστα δουλειών** ομαδοποιημένη ανά ημερομηνία, με φίλτρα: Όλα / Γάμοι-Βαφτίσεις / Με Drone / Με Δεξίωση.
- **Προσθήκη/επεξεργασία δουλειάς**: πελάτης, τύπος (Γάμος, Βάφτιση, Γάμος & Βάφτιση, Σχολική
  Εκδήλωση, Παράσταση, Άλλο), ώρα & διάρκεια μυστηρίου, εκκλησία (όνομα + διεύθυνση), αν
  χρειάζεται drone, και προαιρετικά στοιχεία δεξίωσης (κέντρο, διεύθυνση, ώρα, διάρκεια) αν
  υπάρχει δεξίωση μετά.
- **Έλεγχος σύγκρουσης**: πριν αποθηκευτεί μια δουλειά, ελέγχεται αν επικαλύπτεται χρονικά με
  κάποια ήδη κλεισμένη δουλειά, και σε προειδοποιεί πριν την αποθηκεύσεις.
- **Χρόνος διαδρομής**: υπολογίζει (μέσω Google Directions API) πόση ώρα κάνεις από το σπίτι
  μέχρι την εκκλησία, και από την εκκλησία μέχρι το κέντρο δεξίωσης αν υπάρχει, με κουμπί για
  άνοιγμα της διαδρομής στο Google Maps.
- **Ημερολόγιο συσκευής**: κατά την αποθήκευση, επιλέγεις σε ποιο ημερολόγιο της συσκευής να
  μπει η δουλειά (π.χ. ο λογαριασμός σου Google ή το Samsung Calendar) και δημιουργείται
  ξεχωριστό event για το μυστήριο και, αν υπάρχει, για τη δεξίωση - και τα δύο με υπενθύμιση
  όσα λεπτά πριν ορίσεις στις Ρυθμίσεις (προεπιλογή 120 λεπτά = 2 ώρες). Η ίδια η υπενθύμιση/
  ειδοποίηση γίνεται από την εφαρμογή ημερολογίου (Google Calendar ή Samsung Calendar), όχι από
  το JobClosure - έτσι δουλεύει σωστά με όποια εφαρμογή ημερολογίου χρησιμοποιείς ήδη.
- **Ειδοποίηση συνεργάτη για Drone**: όταν ενεργοποιείς το Drone σε μια δουλειά, ο συνεργάτης
  που έχεις ορίσει στις Ρυθμίσεις προστίθεται ως καλεσμένος στο event του ημερολογίου. Σε ημερολόγιο Google αυτό κάνει δύο πράγματα ταυτόχρονα: του
  στέλνει αυτόματα email πρόσκλησης, και η δουλειά εμφανίζεται στο δικό του ημερολόγιο μόλις
  αποδεχτεί - χωρίς να χρειάζεται ξεχωριστό μηχανισμό αποστολής email. Αν σβήσεις το Drone σε
  μια δουλειά αργότερα, η πρόσκληση αφαιρείται αυτόματα.
- **Συνθήκες για Drone**: όταν μια δουλειά έχει Drone ενεργό, η οθόνη λεπτομερειών δείχνει για
  την εκκλησία (και το κέντρο δεξίωσης, αν υπάρχει) τρέχουσα θερμοκρασία/καιρό, ταχύτητα και
  διεύθυνση ανέμου, και υψόμετρο της περιοχής - χρήσιμα στοιχεία πριν πετάξεις. Ο καιρός και το
  υψόμετρο έρχονται από το [Open-Meteo](https://open-meteo.com/) (δωρεάν, χωρίς API key), αφού
  πρώτα μετατραπεί η διεύθυνση σε συντεταγμένες μέσω του ίδιου πάροχου (OpenStreetMap ή Google
  Maps) που έχεις επιλέξει για τον χρόνο διαδρομής.
- **Έλεγχος ζωνών για Drone**: στο ίδιο σημείο υπάρχει κουμπί που ανοίγει απευθείας το
  [Drone Aware - GR (DAGR)](https://dagr.hasp.gov.gr/) - το επίσημο σύστημα προπτητικού ελέγχου
  της ΥΠΑ/HASP για την Ελλάδα. Το DAGR δεν έχει δημόσιο API για ενσωμάτωση σε τρίτες εφαρμογές
  (είναι portal με σύνδεση λογαριασμού), οπότε η εφαρμογή απλώς σε πηγαίνει εκεί με ένα tap αντί
  να προσπαθεί να "μαντέψει" τα δεδομένα του - πάντα να κάνεις εκεί την τελική επιβεβαίωση πριν
  από κάθε πτήση, ειδικά κοντά σε αεροδρόμια ή στρατιωτικές περιοχές.
- **Ειδοποίηση για ενημερώσεις**: όταν ανοίγεις την εφαρμογή, ελέγχεται αυτόματα αν υπάρχει νεότερη
  έκδοση δημοσιευμένη στο GitHub Release `debug-latest` του repository. Αν ναι, εμφανίζεται
  ειδοποίηση Android, και στις Ρυθμίσεις υπάρχει κουμπί **Λήψη & Εγκατάσταση** που κατεβάζει το
  APK (μέσω του συστήματος λήψεων του Android) και ανοίγει κατευθείαν τον installer - χωρίς να
  χρειάζεται να πας στο GitHub. Την πρώτη φορά θα σου ζητηθεί άδεια "εγκατάσταση από άγνωστες
  πηγές" για το JobClosure· η εφαρμογή σε πηγαίνει αυτόματα στις σωστές ρυθμίσεις για αυτό.
  Αν το repository μείνει **private**, χρειάζεται ένα GitHub token στο πεδίο "GitHub token" των
  Ρυθμίσεων (δες παρακάτω) - αλλιώς η ενότητα "Ενημερώσεις" απλώς θα δείχνει σφάλμα ελέγχου.

## Δομή project

Kotlin + Jetpack Compose, Room (τοπική βάση δεδομένων για τις δουλειές), DataStore (ρυθμίσεις:
διεύθυνση σπιτιού, API key, λεπτά υπενθύμισης), Retrofit/Moshi (κλήση στο Google Directions API),
και το `android.provider.CalendarContract` για εγγραφή στο ημερολόγιο της συσκευής.

```
app/src/main/java/gr/gtar/jobclosure/
  data/              Booking entity, Room DAO/DB, repositories
  calendar/          CalendarHelper (CalendarContract integration)
  network/           Google Directions API client
  ui/                Compose screens ανά οθόνη (bookinglist, bookingedit, bookingdetail, settings)

shared/src/main/kotlin/gr/gtar/jobclosure/shared/
  model/             Booking + έλεγχος σύγκρουσης (κοινό μεταξύ Android και desktop)
  calendar/          Google Calendar API client (Ktor) + OAuth2 token exchange
  network/           Ktor HttpClient factory

desktopApp/src/main/kotlin/gr/gtar/jobclosure/desktop/
  auth/              Google OAuth sign-in (loopback browser flow) + τοπικές ρυθμίσεις
  ui/                Compose Desktop οθόνες (sign-in, λίστα, προσθήκη/επεξεργασία)
```

Το `shared` module είναι σκόπιμα plain Kotlin/JVM (όχι πλήρες Kotlin Multiplatform με Android/iOS
target) - έτσι μεταγλωττίζεται με το ίδιο Gradle toolchain και στα δύο apps, χωρίς να χρειάζεται
πρόσθετο Android tooling μέσα στο κοινό module.

## Άνοιγμα / Build

Το πιο απλό είναι να ανοίξεις τον φάκελο του project στο **Android Studio** (Koala ή νεότερο) -
θα κατεβάσει μόνο του το Android SDK/toolchain που λείπει και θα κάνει sync. Μετά απλά τρέχεις
την εφαρμογή σε συσκευή ή emulator (▶ Run).

Εναλλακτικά, από terminal με το Android SDK ήδη εγκατεστημένο:

```bash
./gradlew assembleDebug
```

> Σημείωση: αυτό το project γράφτηκε χωρίς πρόσβαση σε Android SDK/emulator, οπότε δεν έχει
> μεταγλωττιστεί εδώ - θα χρειαστεί ένα πρώτο build στο Android Studio για να πιάσεις τυχόν
> μικρό typo, αν και ο κώδικας έχει ελεγχθεί προσεκτικά γραμμή-γραμμή.

**Ελάχιστη έκδοση Android:** 8.0 (API 26) - χρειάζεται για τα adaptive icons και το ενσωματωμένο
`java.time`.

## Πάροχος χαρτών/διαδρομών: OpenStreetMap ή Google Maps

Στις Ρυθμίσεις διαλέγεις ποια υπηρεσία υπολογίζει τον χρόνο διαδρομής, τη μετατροπή διεύθυνσης σε
συντεταγμένες (για τον καιρό/υψόμετρο του drone) και το κουμπί "Άνοιγμα διαδρομής":

- **OpenStreetMap (προεπιλογή)** - δωρεάν, χωρίς κανένα API key: γεωκωδικοποίηση μέσω
  [Nominatim](https://nominatim.openstreetmap.org/) και υπολογισμός διαδρομής μέσω
  [OSRM](https://project-osrm.org/) (δημόσιος demo server). Το κουμπί "Άνοιγμα διαδρομής" ανοίγει
  το openstreetmap.org. Καμία ρύθμιση δεν χρειάζεται - δουλεύει αμέσως.
- **Google Maps** - χρειάζεται δικό σου API key:
  1. [Google Cloud Console](https://console.cloud.google.com/) → δημιούργησε ή χρησιμοποίησε ένα project.
  2. Ενεργοποίησε το **Directions API** και το **Geocoding API** (χρειάζονται και τα δύο).
  3. Δημιούργησε ένα API key (Credentials → Create Credentials → API key), και περιόρισέ το ώστε
     να λειτουργεί μόνο με αυτά τα δύο API, για ασφάλεια.
  4. Άνοιξε την εφαρμογή → Ρυθμίσεις → επίλεξε "Google Maps" → βάλε το key.

Και στις δύο περιπτώσεις, βάλε και τη διεύθυνση του σπιτιού σου στις Ρυθμίσεις (αφετηρία για τον
υπολογισμό χρόνου διαδρομής).

## Ρύθμιση GitHub token (μόνο αν το repository μείνει private)

Ο έλεγχος ενημερώσεων μέσα από την εφαρμογή χρησιμοποιεί το GitHub API για να διαβάσει το πιο
πρόσφατο Release. Σε ένα **public** repository αυτό δουλεύει χωρίς κανένα token. Σε **private**
repository χρειάζεται ένα δικό σου token:

1. GitHub → πάνω δεξιά avatar → **Settings** → **Developer settings** (κάτω-κάτω αριστερά) →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Στο **Repository access**, επίλεξε **Only select repositories** και διάλεξε μόνο το `JobClosure`.
3. Στο **Permissions** → **Repository permissions**, βρες **Contents** και βάλε **Read-only**
   (τίποτα άλλο δεν χρειάζεται).
4. Δημιούργησε το token και αντέγραψέ το (φαίνεται μία μόνο φορά).
5. Άνοιξε την εφαρμογή → Ρυθμίσεις → βάλε το στο πεδίο "GitHub token (για ιδιωτικό repo)".

Το token αποθηκεύεται μόνο τοπικά στη συσκευή σου (όχι στο source code, όχι στο APK) - αλλά
σκέψου το εξής: όποιος έχει πρόσβαση στη συσκευή σου/στα δεδομένα της εφαρμογής θα μπορούσε
θεωρητικά να το διαβάσει, οπότε δώσε του μόνο το ελάχιστο δικαίωμα (Contents: Read-only, μόνο
αυτό το repo) όπως παραπάνω, ώστε ακόμα κι αν διέρρευε να μην ανοίγει τίποτα άλλο.

## Desktop εφαρμογή (Windows / macOS / Linux)

Ο desktop client δεν έχει δικό του server - χρησιμοποιεί το **Google Calendar σου ως μηχανισμό
συγχρονισμού**. Μια κράτηση που φτιάχνεις στο κινητό γράφεται σαν event(s) στο ημερολόγιο Google
που έχεις επιλέξει· ο desktop client διαβάζει/γράφει στο **ίδιο ημερολόγιο** μέσω του Google
Calendar API, οπότε ό,τι φτιάχνεις στη μία συσκευή εμφανίζεται στην άλλη μόλις συγχρονίσει το
Google Calendar - όχι στιγμιαία, αλλά χωρίς κανένα επιπλέον session/λογαριασμό JobClosure. Τα
στοιχεία της κράτησης (τύπος, drone, όνομα χώρου κ.λπ.) κωδικοποιούνται σαν μια κρυφή γραμμή μέσα
στο πεδίο περιγραφής του event - γι' αυτό λειτουργεί με το ήδη υπάρχον, χωρίς τίποτα ειδικό να
χρειάζεται να υποστηρίξει το Google Calendar.

### Build / εκτέλεση

```bash
./gradlew :desktopApp:run
```

Για ένα εγκαταστάσιμο πακέτο (χρειάζεται να τρέξει στο αντίστοιχο λειτουργικό - το CI το κάνει
αυτόματα σε κάθε build, δες `.github/workflows/build-apk.yml`):

```bash
./gradlew :desktopApp:packageDistributionForCurrentOS
```

Βγάζει `.msi` σε Windows, `.dmg` σε macOS, `.deb` σε Linux, μέσα στο
`desktopApp/build/compose/binaries/main/`.

### Ρύθμιση Google OAuth Client (μία φορά, ανά υπολογιστή)

Ο desktop client χρειάζεται δικό του OAuth "Desktop app" client στο Google Cloud, για να μπορεί να
σου ζητήσει άδεια πρόσβασης στο Calendar σου:

1. [Google Cloud Console](https://console.cloud.google.com/) → δημιούργησε ή διάλεξε ένα project.
2. Ενεργοποίησε το **Google Calendar API**.
3. **OAuth consent screen**: όρισέ το σαν *External* (ή *Internal* αν έχεις Google Workspace) και
   πρόσθεσε τον εαυτό σου σαν test user - αρκεί, δεν χρειάζεται δημοσίευση/review αφού το
   χρησιμοποιείς μόνο εσύ.
4. **Credentials → Create Credentials → OAuth client ID**, τύπος **Desktop app**.
5. Αντέγραψε το **Client ID** και το **Client Secret** που θα δημιουργηθούν.
6. Άνοιξε τον desktop client, βάλε τα στα αντίστοιχα πεδία, και πάτα **Σύνδεση με Google** - θα
   ανοίξει ο browser σου για το login/έγκριση, και μετά επιστρέφεις αυτόματα στην εφαρμογή.
7. Διάλεξε ποιο ημερολόγιο θα είναι το σημείο συγχρονισμού - **το ίδιο** που έχεις επιλέξει και
   στο κινητό, ώστε να βλέπονται οι ίδιες κρατήσεις και στις δύο συσκευές.

Client ID/Secret και το refresh token αποθηκεύονται τοπικά σε `~/.jobclosure/config.properties` -
όχι στο source code, όχι στο repository.

## Άδειες

- **Ημερολόγιο (READ_CALENDAR / WRITE_CALENDAR)**: για να μπορεί να διαβάσει ποια ημερολόγια
  (λογαριασμοί) υπάρχουν στη συσκευή και να γράψει το ραντεβού σε αυτό που θα διαλέξεις.
- **Internet**: για τις κλήσεις στον επιλεγμένο πάροχο χαρτών (OpenStreetMap: Nominatim + OSRM, ή
  Google Directions/Geocoding API), στο Open-Meteo, και για τον έλεγχο ενημερώσεων στο GitHub.
- **Ειδοποιήσεις (POST_NOTIFICATIONS)**: για να σε ειδοποιεί όταν βρεθεί νέα έκδοση.
- **Εγκατάσταση αγνώστων εφαρμογών (REQUEST_INSTALL_PACKAGES)**: για να μπορεί να ανοίξει τον
  installer απευθείας μετά τη λήψη μιας ενημέρωσης.

Δεν χρειάζεται δικό του λογαριασμό ή server. Στο Android, οι δουλειές μένουν πάντα τοπικά στη
συσκευή (Room database) - το ημερολόγιο (Google/Samsung Calendar) είναι απλά αντίγραφο για τις
υπενθυμίσεις. Αν θέλεις να βλέπεις τις ίδιες κρατήσεις και σε desktop, χρησιμοποίησε το Google
Calendar σαν σημείο συγχρονισμού όπως περιγράφεται παραπάνω - διαφορετικά, χωρίς desktop client,
οι δουλειές δεν μεταφέρονται αυτόματα σε άλλη συσκευή.
